# Java Day 23 - Sum of Odd Numbers

This program calculates the sum of odd numbers from 1 to 20 using a `while` loop.

## Output

```text
Sum of odd numbers = 100
```

## Concepts Used

- `while` loop
- Variables
- Addition
- Increment by 2
- `System.out.println()`

## How It Works

The program starts with `number = 1` and `sum = 0`. The `while` loop adds each odd number to `sum` until the number becomes greater than 20. The number increases by 2 in every iteration.
